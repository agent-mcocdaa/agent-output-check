Your character card got worse after you "optimized" the preset? I'll measure it for free

Not selling cards or fine-tuning here. One measured fact first: "the character stopped sounding like itself after I changed settings" is usually the settings and the card, not the model.

We ran a paired test: same tutorial-style edit (global system prompt + example dialogues + sampling caps) applied to three character cards, 5 repeated runs × 8 turns before and after = 240 real model replies. All three cards got shorter (91→52, 57→48, 121→64 chars), but only one card was consistently worse across all 5 repeats — the other two flipped direction between runs. So a single lucky roll will mislead you; you need repeated paired runs before you blame the model (and before anyone sells you a LoRA).

If you have a chat log, I'll give you a check-up: which replies drifted, in which way (speaking for the player / getting longer and longer / looping the same block / stock phrases / breaking character / half-sentence cut-offs), and which single thing to fix first — the card, the preset, or the sampler. We pay the compute; no diagnostic fee. If the honest answer is "don't train anything", that's what you'll get.
