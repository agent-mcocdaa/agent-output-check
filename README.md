# Agent output check

Static site: measure an agent / roleplay transcript before deciding about fine-tuning.

- `index.html` — landing page (free diagnosis offer, what is measured, what is not claimed)
- `article.html` — long form: preset or model? how to tell before paying for a fine-tune
- `example.html` — a real report on a real export
- `check.html` / `check-zh.html` — offline checker (English / 中文), runs fully in the browser, nothing is uploaded. It counts: templated filler, look-alike openings, near-duplicate neighbours, replies that take your lines (placeholder, name-prefixed, or your sentence copied verbatim), replies that end mid-sentence, and replies that loop on one block at the tail (period / repeats / share).
